# 🌍 Trail Bliss – Tourism Web Application

Trail Bliss is a full-stack tourism web application that helps users explore tourist places, check climate safety, and book offline guides.

---

## 🚀 Features

-> Secure Login System

-> State-wise tourist place listing

-> Search and filter tourist places

-> Climate & safety info (shows whether it’s safe to travel or not)

-> Offline guide booking system

-> Guide dashboard and schedules

-> Feedback and review system

---

## 🛠 Tech Stack

-> HTML  

-> CSS  

-> JavaScript  

-> Node.js  

-> MongoDB  

---
